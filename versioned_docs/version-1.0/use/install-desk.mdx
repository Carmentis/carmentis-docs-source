# Get Carmentis Desk

Carmentis Desk is a cross-platform application developed to handle all common tasks related to
the Carmentis ecosystem. It is mainly developped for users wanting to stake tokens and for Carmentis-featured application developpers. End-users may also
enjoy Carmentis Desk for its wallet-management feature.

![](/img/desk/wallet.png)


## Features

Carmentis Desk allows you to:
- Manage your wallets: You can create and manage multiple wallets. Inside each wallet, you can create and publish organizations, applications and nodes.
- Manage your nodes: It includes the ability to claim (running and unclaimed) nodes, stake on these nodes and monitor their status.
- Administrate your operators: An operator is a server able to build and publish transactions via an easy-to-use API.
