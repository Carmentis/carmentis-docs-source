# Workspace


The Workspace is a personalized environment managed by a designated set of administrators, enabling developers to 
integrate their web applications with the Carmentis protocol. Within the Workspace, administrators and developers 
define the specific data to be stored on the blockchain, creating an [Application definition](./application) that outlines which event
details are recorded. They also control the visibility of each data field, specifying whether it will be public,
private, or end-to-end encrypted. This structure allows administrators to ensure that sensitive information is 
securely managed, while still supporting transparency where necessary, giving fine-grained control over how 
applications interact with the blockchain.


For more information about the usage of a workspace, we refer you to our [Create your workspace](../how-to/create-workspace) 
and our [Manage your workspace](../how-to/manage-workspace) pages.
