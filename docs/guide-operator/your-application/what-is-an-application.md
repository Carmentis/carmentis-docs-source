# What is an application

A Carmentis application is an instance of a signer that must be used to save record proofs for your end-users. To use the features of the Carmentis network, you must register your application on the Carmentis network and deploy it on the chain.

Then you have to implement on your side the necessary features to interact with the Carmentis network through the operator server.
